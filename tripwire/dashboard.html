TripWire is an application-level simulation: no OS firewall rules are changed, no real email is sent, and the adversary only targets this process. HMAC keys protect integrity and origin towards the gateway; there is no transport encryption or non-repudiation. A stolen agent key used for an in-policy message cannot be distinguished from the real agent. See README "Limitations".
