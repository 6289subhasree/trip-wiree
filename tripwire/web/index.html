02 · The principle

Authority ≠ content.

TripWire labels where every word came from. Trusted sources can authorise a tool. Untrusted ones can only be quoted as evidence, however convincing they sound.

Can authorise

Trusted

  • ✓System policy: tools, limits, destinations
  • ✓The task a human assigned
  • ✓A human approval for high-impact actions
Evidence only

Untrusted

  • ×Invoices, attachments and web pages
  • ×Tool outputs and retrieved records
  • ×Anything an agent says about itself

Every message and every tool call passes one checkpoint.
